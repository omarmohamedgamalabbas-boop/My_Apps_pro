# My Apps — حالة المشروع

هذه النسخة هي مشروع Android قابل للبناء، وليست APK جاهزًا بعد.

## ما تم تجهيزه
- واجهة Jetpack Compose عربية باسم My Apps.
- اختيار ملفات ومجلدات.
- بروتوكول نقل محلي مع AES-GCM وSHA-256.
- استكمال جزئي للملفات عبر ملفات `.part`.
- QR للاتصال.
- خادم مشاركة للكمبيوتر من المتصفح.
- نسخ جهات الاتصال/SMS/سجل المكالمات عند منح الصلاحيات.
- حذف مؤجل للملفات داخل مساحة التطبيق.
- GitHub Actions لبناء APK Debug في السحابة.

## قبل الإصدار التجاري
يجب اختبار النقل بين جهازين فعليين، Wi-Fi Direct، الملفات الضخمة، انقطاع الاتصال، التوافق مع إصدارات Android المختلفة، وإضافة نظام الإعلانات/الدفع بعد إنشاء الحسابات والمفاتيح الرسمية.
